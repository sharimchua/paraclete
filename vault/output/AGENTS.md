# Output Directory Directives

The `output/` directory contains compiled views, aggregated dashboards, client preparation briefs, client dossiers, and catalogs generated deterministically from the canonical knowledge in `okf/`.

## Subfolder Structure
- `dashboards/`: Overall practice overview (`practice-overview.md`) and cohort/group overviews (`<group-slug>-overview.md`).
- `dossiers/`: Synthesized client dossiers and session history digests (`<person-slug>-dossier.md`).
- `briefs/`: Preparation briefs for upcoming client sessions (`<person-slug>-session-brief.md`).
- `library/`: Categorized intellectual capital reference catalogs (`reference-catalog.md`).

## Directives
1. **Never edit files directly in `output/`**: Any manual changes will be overwritten upon the next run of `paraclete generate`.
2. **Template Driven**: All files in this directory are produced by compiling templates found in `templates/` using the in-memory entity graph of `okf/`.
3. **Banner Notice**: Generated files should begin with:
   `<!-- AUTO-GENERATED BY PARACLETE - DO NOT EDIT DIRECTLY -->`
